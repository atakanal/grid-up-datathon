# Yarışmada gönderilen en iyi dosyalar

Bu klasörde yalnızca genel liderlik tablosunda en iyi skoru alan iki submission
dosyamız tutulur.

| Sürüm | Genel RMSLE | Dosya |
|---|---:|---|
| V108 | **0,99430** | `gridup_v108_uniform_endpoint_candidate.csv` |
| V96b | **0,99676** | `gridup_v96b_fresh_warm_challenger.csv` |

Dosyalar düzenlenmemeli veya yeniden dışa aktarılmamalıdır. Byte düzeyindeki
SHA-256 değerleri `sonuclar/liderlik_sonuclari.json` dosyasında dondurulmuş ve
GitHub Actions tarafından otomatik olarak kontrol edilmektedir.
